# NLP PDF Processing Assignment

##  Objective
This assignment performs complete NLP processing on a PDF file including:
- Text extraction
- Preprocessing using Regex
- Feature extraction (One Hot Encoding, TF-IDF)
- Visualization using Plotly

##  Dataset
Book used: Pride and Prejudice (Jane Austen)  
Source: https://www.gutenberg.org/files/1342/1342-pdf.pdf

## ️ How to Run
1. Install libraries:
   pip install PyPDF2 nltk scikit-learn plotly pandas

2. Run notebook.ipynb step by step

##  Outputs
- Total pages extracted
- Cleaned text
- Stopword removal
- Stemming & Lemmatization
- One Hot Encoding
- TF-IDF features
- Plotly scatter plot
